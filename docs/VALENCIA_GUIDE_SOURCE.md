## 2. Главные правила поездки

- Один логический район на полдня.
- Не ездить через город ради перекуса.
- Основной хороший приём пищи – обед около 13:00–13:30.
- Вечером – лёгкая еда.
- Исключение – тапас-ужин в день прилёта.
- Активность на улице до 13:00 или после 17:30.
- После обеда – отдых или помещение с кондиционером.
- Такси предпочтительнее сложной пересадки для группы из четырёх человек.
- Рестораны должны быть семейными, с нормальными порциями и понятной едой.
- Не выбирать место только ради Michelin.
- Не использовать brunch-кафе с avocado toast.
- Не повторять один ресторан без причины.
- Любой опциональный пункт можно отменить без ощущения, что день испорчен.
