# Valencia 2026 — семейный виртуальный гид

Mobile-first PWA для семейной поездки в Валенсию **22–26 июля 2026**
(3 взрослых, включая пожилого человека, и ребёнок 6 лет).

Приложение отвечает на главные вопросы поездки: что мы делаем сейчас, когда
выходить, пешком или такси, где едим, подтверждена ли бронь, что заказать,
что рассказать ребёнку, что отменить если жарко, и где быстро поесть без брони.

**Источник данных:** `VALENCIA_GUIDE_SOURCE.md` (единственный источник логики
и контента). Все данные приложения лежат в `src/data/*.json`.

## Stack

React · Vite · TypeScript · Leaflet + OpenStreetMap · vite-plugin-pwa
(offline shell + кеш тайлов) · localStorage · GitHub Actions → GitHub Pages.

## Страницы

| Маршрут | Что там |
| --- | --- |
| `#/` | Сегодня: текущий и следующий пункт, «когда выходить», кнопки «Мы устали» и «Нужна еда», план B |
| `#/days` | Все 5 дней по часам, статусы броней, планы B |
| `#/map` | Интерактивная карта: цвета по категориям, карточка точки |
| `#/guide` | Рассказы о местах по дням — читать вслух для travel-видео |
| `#/food` | Рестораны: статус, что заказать, фразы, этикет, еда без брони, стоп-лист |
| `#/missions` | Детские миссии: истории, вопросы, значки (прогресс в localStorage) |
| `#/phrases` | Ресторанные фразы EN/RU, копирование по тапу |
| `#/emergency` | 112, отель, медицина, страховка |
| `#/more` | Настройки: тема, режим «показывать день», чек-лист, правила, источники |

Пуш в `main` автоматически собирает и публикует приложение на GitHub Pages

## Обновление данных

Весь контент — в `src/data/`:

- `trip.json` — правила, брони, чек-лист, экстренная информация, глоссарий еды;
- `itinerary.json` — расписание по дням (`items` с временем, `optional: true`
  скрывается кнопкой «Мы устали»);
- `places.json` — точки карты: координаты, категория, карточка
  (`verificationStatus: "verify"` показывает чип «проверить перед поездкой»);
- `restaurants.json` — ресторанные карточки (заказ, фразы, этикет, план B);
- `stories.json` — детские истории и миссии;
- `guide.json` — рассказы о местах для чтения вслух (страница «Гид»);
- `phrases.json` — фразы EN/RU.

После правки данных: закоммитить в `main` — деплой обновится сам.

### Изменение статуса брони

Статус меняется в **двух** файлах (они должны совпадать):

1. `src/data/trip.json` → `reservations[].status`
2. `src/data/places.json` → у той же точки `reservationStatus` **и** категория:
   `confirmed-restaurant` / `pending-restaurant` / `candidate-restaurant`
3. `src/data/restaurants.json` → `status` у того же ресторана.

Например, когда Navarro подтвердят: `pending → confirmed` в трёх местах.

### Координаты и навигация

Кнопка «Открыть маршрут» строит маршрут в Google Maps по **текстовому адресу**
(`navQuery` в `places.json`) — это точнее координат. Координаты используются
только для пинов на карте (точность ±50–100 м). Адреса ресторанов проверены по
официальным сайтам и справочникам; точки со статусом `verify` требуют финальной
проверки перед поездкой.

## Offline-проверка

1. Открыть опубликованное приложение, походить по страницам (и по карте —
   просмотренные тайлы закешируются).
2. Включить авиарежим и перезагрузить страницу: приложение и данные работают
   офлайн; карта показывает только уже просмотренные участки (тайлы OSM
   кешируются по мере просмотра, до 600 тайлов на 30 дней).
3. В DevTools: Application → Service Workers — `sw.js` активен;
   Cache Storage — precache приложения и `osm-tiles`.
